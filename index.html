Compiler-X

// High-Performance Containerized Execution Platform

Compiler-X solves the complexity of running arbitrary user code securely in the cloud. By pairing an intuitive Monaco Code Editor frontend with an isolated Docker container backend in Node.js, code is compiled and executed in ephemeral sandboxes with strict CPU, memory, and timeout governance.

  • ✔ Multi-Language Support: Python 3, Java, C, C#, JavaScript, Scala, Kotlin, and HTML.
  • ✔ Docker Container Isolation: Ephemeral container runners with Linux cgroups (128MB RAM limit & process PID caps).
  • ✔ Monaco Editor Integration: Professional VS Code editing experience with syntax highlighting and autocompletion.
  • ✔ Resilient API: Node.js & Express streaming runner with rapid cleanup cycles under 200ms.
