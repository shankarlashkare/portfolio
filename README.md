## 🌟 Overview

A ultra-clean, production-ready, fully responsive developer portfolio built with modern semantic HTML5, pure CSS3 design tokens, and vanilla JavaScript. Features an interactive code runner simulation for **Compiler-X** (isolated multi-language compiler), a smooth Dark/Light mode switcher, a curriculum vitae modal, and an interactive contact interface.

---

## 🚀 Key Features

- **Apple / Vercel Aesthetic:** Clean typography (`Plus Jakarta Sans`, `Inter`, `JetBrains Mono`), glassmorphic navigation, ambient radial gradients, and subtle hairline borders.
- **Dark & Light Mode Toggle:** Smooth transition switch located in the sticky header with `localStorage` persistence and system color scheme detection.
- **Custom "SL" Monogram Brand:** Geometric SVG logo with high-end glassmorphic gradient touch.
- **Framed Profile Card:** Elegantly framed photo card with an active status badge (`🟢 Open to Work / Full-Stack Engineer`), floating tech chips, and 3D tilt effects.
- **Compiler-X Interactive Playground:** Flagship project showcase with a live code editor simulation supporting **Python, Java, C, JavaScript, C#, Scala, and Kotlin**. Simulates containerized Docker execution with real-time stdout logs and latency metrics.
- **Skills Filtering System:** Categorized skills (Languages, Backend & DevOps, Tools & Concepts) with live category filtering and animated proficiency progress bars.
- **Interactive Resume Modal:** Pop-up Curriculum Vitae summary with simulated PDF download and print integration.
- **Responsive Layout:** 100% mobile-friendly with mobile-first CSS Grid, Flexbox, and an animated hamburger drawer menu.

## 🛠️ Tech Stack

## 💻 Local Setup & Running

No build steps or complex dependencies required!

### Option 1: Direct in Browser
Double-click `index.html` or open it with Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Local HTTP Server (Python / Node)
```bash
# Using Python
python -m http.server 8080

# Using Node (npx)
npx serve .
```
Then navigate to `http://localhost:8080/`.
